# SVG template design lab

PR90 is integrated as an isolated `/stub-lab` design study with eight SVG templates, both faces, synthetic sample events and self-hosted assets. It does not expose template IDs through the customer style picker. Current main landing, reduced-motion behavior, package pins, customer editor/rendering, exact downloads, fact identity/inclusion and approval bindings remain unchanged.

The original customer picker integration is deliberately deferred: template-specific exact export dimensions/readiness, printed fact ordering/identity and overflow proofs, and approval composition mapping are not implemented or qualified. Re-enabling it requires those source boundaries and their regression evidence. A lab screen/print rendering is not a production artifact, accepted manufacturing spec or orderable product. This source merge does not establish rights, provider, host or canonical acceptance and does not deploy assets or pages.

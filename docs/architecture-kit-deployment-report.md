# Architecture kit v1.0 deployment report

Documentation distribution completed October 10, 2026. All fourteen repositories existed at inspection; twelve were empty and received signed, meaningful documentation baselines. No repositories needed creation. The application is public; the other thirteen remain private. Existing visibility, licenses, brand assets, configuration and unrelated local work were preserved. No application code or placeholder applications were created.

> **Historical point-in-time record (2026-10-10).** The visibility count and repository descriptions below record that day's deployment inspection; they are not current organization visibility data. Subsequent source and visibility changes are tracked in the maintained [current architecture and integration state](architecture/CURRENT-STATE.md). The immutable kit remains a design snapshot, and this report preserves its historical evidence.

The complete original kit has 32 files under `docs/architecture-kit/v1.0/`, including Markdown/PDF/DOCX architecture, diagrams and Mermaid sources, briefs, planning, changelog and checksums. Every file is byte-identical in the published Git tree. The original snapshot retains historical proposed statuses; the active inventory and ownership documents record verified existence. Maintain promoted copies rather than editing the snapshot.

The application composes the customer journey and owns identity, projects, orders and purchase authorization. The harness owns durable execution, typed decisions, bounded retries, checkpoints, cancellation and recovery. Event intelligence owns sourced facts, safe retrieval and asset candidates. Creative engine owns GPT Image integration, dynamic controls, immutable artwork and edits. Print production owns exact vector text, raster/vector composition, personalization, preflight and exports. Fulfillment owns supplier quotes, idempotent submissions and external observations. Cost intelligence owns metering, reservations, financial postings and reconciliation; the dashboard presents its results through application-enforced access. Shared contracts owns versioned interfaces and compatibility. Integration evaluations owns cross-system verification and evidence. Brand, landing and marketing own identity and promotional presentation; `.github` documents governance.

The proposed runtime is one web application, one worker, PostgreSQL and object storage, not fourteen independently deployed services. Framework defaults remain proposals. No migration or provider configuration was performed. The repository map is planning data, not a tested dependency lockfile; no component commit pins were invented.
